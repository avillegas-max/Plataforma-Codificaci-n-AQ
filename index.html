Control de codificación

La plataforma verifica la documentación antes de asignar un nuevo código.

  1. Selecciona Documentación Interna o Proyecto.
  2. Ingresa los datos del documento.
  3. El sistema consulta el Listado Maestro y la Matriz de Trazabilidad.
  4. Se identifica el último correlativo utilizado.
  5. Se verifica que el código no exista.
  6. El documento queda disponible para registro.

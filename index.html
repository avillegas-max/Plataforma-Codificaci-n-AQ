Cómo funciona

  1. Seleccionas Documentación Interna o Proyecto.
  2. La plataforma consulta el Listado Maestro y la Matriz.
  3. Busca códigos existentes y calcula el siguiente correlativo.
  4. Si el código ya existe, lo informa y bloquea el registro.
  5. Si está disponible, registra el documento en ambos controles.

Nuevo documento

El código se calcula a partir de la documentación existente. No se escribe manualmente el correlativo.
